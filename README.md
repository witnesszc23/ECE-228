# ECE-228
To reuse our code is simple and straightforward. 
1. Download the 'solor.csv' and our notebook to your computer and make sure they are in the same directory.
2. We used the packages that are frequently used but in case you did not install them, you can run the code first and check if you need any new package.

After these two steps, you should be able to run our notebook and see the results.
